# FragileDiskCopy / 脆盘安全拷贝

面向不稳定磁盘的 Windows 限速、断点续拷工具。程序优先保护源盘，使用持续限速、顺序读取、文件级与文件内偏移续传，并提供掉盘暂停、卡住检测和动态调速。

> 适用于“需要尽量抢救数据，但源盘已经无法承受正常高速读取”的场景。它不是数据恢复或坏道修复软件。

[下载最新发布版](https://github.com/qq290223322/FragileDiskCopy/releases/latest)

## 主要功能

### 稳定读取与断点续拷

- 默认以较低速度开始读取，避免任务启动瞬间给不稳定磁盘造成过大压力。
- 所有模式都从 **0.5 MiB/s 保护速度**起步，再逐步提速。
- 固定限速模式在 10 秒无卡住后增长，最终停在用户设置的基础限速。
- 动态调速模式可设置最高速度和增长间隔，基础限速仍必须低于最高速度。
- 动态调速关闭时不会超过基础限速；开启后最高速由用户设置，不再固定限制为 20 MiB/s。
- 文件使用 `_copy-resume` 临时区保存已写入部分。暂停、退出或掉盘后，再次开始会从当前文件已有偏移继续，而不是重新读取整个文件。
- 源文件大小或修改时间发生变化时，该文件的旧临时数据会被放弃并重新复制。

### 坏盘保护

- 每秒检查源盘和目标盘是否仍在系统中可用。
- 源盘或目标盘断开时自动安全暂停，不会继续批量试错。
- 源文件在清单中仍待处理却突然消失时，按源盘掉盘处理：暂停、增加掉盘次数，并保留待拷贝状态。
- 连续 5 秒没有新增读取字节时记录一次“卡住”，但不会自动暂停或跳过。
- 卡住期间当前文件进度条变为红色，读取恢复后重新变绿；当前速度为 0 B/s 时速度文字也显示红色。
- 卡住持续到第 10、20、30 秒……时，动态限速每次下降 10%，最低保持 0.5 MiB/s。
- 掉盘次数和卡住次数写入清单，重新打开任务后继续累计。

### 多源目录

- “选择 A”支持添加多个源文件夹。
- 只选择一个源文件夹时，直接复制目录内容到目标目录。
- 选择多个源文件夹时，分别复制到目标目录下的同名子目录，例如：

```text
目标目录\
  源文件夹A\
  源文件夹B\
```

- 多个源文件夹同名时拒绝开始，避免文件互相覆盖。
- 多源任务共用一份清单、总进度、掉盘统计和断点续拷状态。

### 扫描与文件类型筛选

- 新增或移除源文件夹后不会自动扫描。
- 点击“扫描文件”只扫描目录、生成或更新清单并刷新列表，不会开始复制。
- 点击“开始 / 继续”时如果清单尚不存在，也会先扫描再复制。
- 文件类型下拉框支持：
  - 全部文件
  - 图片
  - 视频
  - 文档
  - 图片 + 视频
  - 图片 + 视频 + 文档
- 图片、视频、文档分类内部覆盖常见的 JPG、PNG、TIFF、相机 RAW、MP4、MOV、MKV、PDF、Office、文本等格式。
- 当前文件类型选择只筛选界面列表，不改变清单和实际复制范围。

### 文件列表与任务恢复

- 文件列表使用自绘虚拟列表，只绘制可见行，支持数千文件而不会因逐单元格 UI Automation 遍历卡死。
- 列表显示状态、相对路径、大小、精确已处理字节数和错误说明。
- “跟随文件”默认开启：运行中只显示未完成文件并自动定位当前文件；关闭后显示全部文件，已完成项排到后面。
- 正在拷贝的文件显示绿色“正在拷贝”；暂停后恢复为“待拷贝”。
- “继续任务（TSV）”可选择目标目录中的 `_copy-manifest.tsv`，载入全部源目录、文件状态和总进度；选择后仍需点击“开始 / 继续”才会开始复制。

## 使用

### 直接运行

构建并发布后运行：

```text
src\FragileDiskCopy\release\FragileDiskCopy.exe
```

发布物为 Windows x64 自包含单文件，不要求目标机器另外安装 .NET。

### 基本流程

1. 点击“选择 A”，添加一个或多个源文件夹。
2. 选择目标目录 B。
3. 设置基础限速、动态最高速度和增长间隔。
4. 可选：点击“扫描文件”预先生成清单，并选择文件类型筛选。
5. 点击“开始 / 继续”开始复制。
6. 暂停、掉盘或关闭程序后，重新打开并按相同方式继续。

## 清单与临时文件

程序在目标目录写入：

- `_copy-manifest.tsv`：可读的拷贝清单和任务状态。
- `_copy-resume/`：尚未完成文件的临时数据。

**不要删除这两个文件/目录，否则会失去续拷状态。**

清单常用状态：

| 状态 | 含义 |
|---|---|
| `[ ]` | 待拷贝 |
| `[>]` | 正在拷贝；暂停时会恢复为待拷贝 |
| `[x]` | 已完成 |
| `[!]` | 失败 |
| `[E]` | 扫描错误 |
| `[-]` | 已跳过 |

复制成功的文件只有在临时文件完整关闭、长度校验通过并移动到最终路径后才会标记完成。

## 限速与动态调速

### 固定限速

- 基础限速由用户输入。
- 从 0.5 MiB/s 开始。
- 每 10 秒无卡住时增加“基础限速的 10%”。
- 达到基础限速后保持，不会继续增长。

### 动态调速

- 从 0.5 MiB/s 开始。
- 按用户设置的间隔增长，最小 10 秒，默认 10 秒。
- 每次增加“基础限速的 10%”，直到动态最高速度。
- 动态最高速度不再固定限制为 20 MiB/s，但必须严格高于基础限速。
- 卡住持续时每 10 秒下降当前动态速度的 10%，最低保持 0.5 MiB/s。

实际读取速度还会受到源盘性能、缓存、系统调度和目标盘写入速度影响。程序限速是针对本进程读取数据块的持续上限，不能阻止系统搜索、杀毒软件或其他程序访问源盘。

## 已知限制

- 不读取 SMART、温度、供电、坏道重映射或 CRC 等硬件健康信息。
- 不区分“文件被人工删除”和“卷断开导致文件暂时不可见”，两种情况都会按掉盘安全暂停。
- 已完成文件只比较存在性和长度，不做全文哈希校验，避免为了校验再次高速读取坏盘。
- 文件类型筛选只影响列表显示，不限制实际复制范围。
- 当前不支持多个源文件夹映射到同一目标子目录；同名源文件夹会被拒绝。
- 软件无法阻止其他进程访问源盘。

## 数据安全建议

- 首次使用从 0.5～1 MiB/s 开始，观察源盘是否异常。
- 不要同时运行磁盘扫描、照片索引、杀毒全盘扫描等会访问源盘的程序。
- 目标盘应保留足够空间，并避免使用即将故障的磁盘。
- 重要数据完成后，建议在状态较好的另一块盘上做二次备份。
